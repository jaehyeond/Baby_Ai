# Baby Research Directions

- Core identity: a self-growing Baby AI with graph memory, hippocampal-style memory mechanisms, a trainable local core, and eventual embodied action. The LLM is a replaceable language interface, not the full learning system.
- Current J1 diagnostic lesson (2026-07-21): treat graph vocabulary coverage and Local-Core question conditioning as separate bottlenecks. The next bounded step is a read-only content-free/question-shuffle ablation on the same frozen checkpoint; inspect current metrics in `AGENTS.md` and latest `CHANGELOG.md`.
- AI Engram: definition/provenance contract exists; specificity/reactivation/sufficiency/necessity measurements and interventions remain deferred. Do not present graph/provenance analogs as parameter-level engrams.
- Engram Map/3D brain UI: deferred until validated signals exist; visualization must not lend authority to null or contaminated measurements.
- AI-native maintained knowledge graph: Graphify/OpenKB/OpenWiki-like provenance and knowledge maintenance is a candidate capability, but it must preserve source and update provenance.
- Brain2Qwerty/non-invasive neural input: future multimodal direction only. No current neural dataset/hardware claim, and avoid an IRB-dependent path unless the user changes scope.
- Embodiment: Quest 3S + local SmolVLA/llama.cpp experiments support interaction exploration; robotics use requires diverse sensor/action-grounded experience, action verification, and learned-core to wake-behavior wiring.
- Never bundle these candidates into a novelty or top-tier claim without separate evidence for each axis.
